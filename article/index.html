Troubleshooting DNS Error 1001

A workaround for SSL setup issues on websites built with Homestead Website Builder.

Written by Jesse Lito JadulcoFebruary 24, 2024 · For demo purposes

Homestead websites built using Website Builder can be secured using free SSL. Normal SSL installation can be done by updating the A record to point to a secure IP address, which can be found in this Homestead community article. In some cases, however, DNS Error 1001 appears after updating the A record.

The Engineering Team is aware of this problem and is looking for a permanent resolution. As a workaround, follow the instructions below.

  1. Create a temporary website using Website Builder in the Websites Manager page.
    1. Log in to your Homestead account.
    2. Click the Websites Manager tab, then click Add New Website.
    3. Provide a unique name for the site. This is a placeholder until you choose a domain name. Alternatively, you can use the site name with its .homesteadcloud.com URL.
    4. Click Add this Site. If the site name is already in use, choose a different name. Do not enter a domain name here.
    5. If the name is available, you will return to the Websites Manager page.
    6. When ready, click Choose Design.
    7. Select any template for the temporary website. There is no need to publish it.
  2. Associate the domain with the temporary website.
    1. Click the Domains link in the left navigation menu.
    2. Scroll to your domain and click Change Site Association.
    3. Choose the website you want the domain to point to from the drop-down menu.
    4. Click Save to confirm the change. It may take some time to take effect.

    Note: Keep the Homestead Cloud URL for the original website; you will associate the domain with it again later.

  3. Republish the original website without the domain name, using only the Homestead Cloud URL.
  4. After 5–15 minutes, associate the domain with the original website again.
  5. Publish the website with the domain.
  6. Open homesteadssl.com and enter the domain name.
  7. Click Next.

    Note: Disregard differences in the last two digits of the IP address. Homestead uses a secured IP range for SSL certificates.

  8. Advise the customer that propagation can take up to 24 hours.
  9. Delete the temporary website unless the customer asks to keep it.
